# Architecture decision records

Architecture decision records (ADRs) explain important technical choices and their trade-offs. These entries document the current implementation as of 2 November 2026; they are not claims that every choice is permanent.

| ADR | Decision | Status |
| --- | --- | --- |
| 0001 | Keep the runtime dependency-free | Accepted |
| 0002 | Enforce game rules and private data on the server | Accepted |
| 0003 | Keep file persistence single-process and document its limits | Accepted |
| 0004 | Preserve the compatibility bundle with automated parity checks | Accepted |

When a decision changes, add a new ADR rather than silently rewriting the historical reasoning.
